# package manager

- application used to mange the python packages
  - install or uninstall
  - upgrade or downgrade
  - getting information of a package
- options
  - pip
    - is the defualt package manager (installed at the time of python installation)
  - conda
    - popular in data science / machine learning application development
  - uv
    - the modern package manager

## pip

```bash

# install a package
# > pip install <package name>
> pip install numpy pandas matplotlib

# upgrade the package
# > pip install -U <package name>
> pip install -U numpy

# uninstall package
# > pip uninstall <package name>
> pip uinstall numpy

# get the information of a package
# > pip show <package name>
> pip show numpy

```
